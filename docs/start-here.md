# Practical AI Home Lab: choose what you want to build

I've written these books to help you understand AI systems and build practical projects on hardware you control. Start with the foundation if you're new to local AI, or choose the project that fits what you want to do next. These are standalone books in an unordered series.

## Start with your first local model

[The Local LLM Home Lab](https://www.amazon.com/dp/B0HK745294) covers choosing hardware, running private models, measuring performance, and operating a local AI service. Open **Read sample** on the Amazon page to see whether the approach fits you before buying.

## Try a companion before choosing a book

The companion repositories above are public and MIT licensed. Begin with each README's synthetic, deterministic walkthrough; the optional model workflows need their separately documented setup. The projects are teaching systems with explicit limits, not ready-made production services.

Use the immutable edition tag named in each README when following a book. Current branches can contain later corrections and reader guides. Code licenses do not cover the separately published books, artwork, model weights, or other third-party materials.

[Browse Practical AI Home Lab on Amazon](https://www.amazon.com/dp/B0HP7F73K4). Choose the book that fits your next project; you don't need the whole collection to begin.
